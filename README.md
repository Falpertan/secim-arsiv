# Türkiye Halk Oyu Arşivi™

**AlperTan™** — Bağımsız, açık, tarafsız Türkiye seçim ve demografi arşivi.

---

## Ne sunar?

2018-2024 arası Türkiye'nin **13 seçimini** il ve ilçe bazında inceleyebileceğiniz, demografik verilerle birleştirilmiş bir veri görselleştirme platformudur.

### Kapsam

- **13 seçim**: 2018 CB & MV, 2019 BB/BBB/BM/İGM, 2023 CB1/CB2/MV, 2024 BB/BBB/BM/İGM
- **81 il, 973 ilçe** — tüm Türkiye
- **7 yıl demografi** — TÜİK ADNKS yaş/cinsiyet/eğitim verisi
- **Vekil dağılımı** — YSK Resmi Gazete kararları (2018, 2024)
